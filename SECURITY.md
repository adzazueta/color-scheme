# Security policy

Please report security vulnerabilities privately. Do not open a public issue, pull request, or discussion for a vulnerability.

To report one, open the repository's **Security** tab and choose **Report a vulnerability**, or use this link: https://github.com/adzazueta/color-scheme/security/advisories/new

Include as much of the following as you can:

- The affected version of `@adzazueta/color-scheme`.
- Your environment: Node.js or browser, and its version.
- Steps or a minimal reproduction, including the input that triggers the problem (seed colors or a `color-extractor` result).
- The impact you expect.

## Supported versions

Security fixes are released in the latest published version only.

## What happens next

The maintainer reviews the report, coordinates a fix with you, and publishes a GitHub security advisory when the fix is released.
